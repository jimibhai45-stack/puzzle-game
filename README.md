# Candy Blast Pro

A mobile-friendly Candy Crush-style match-3 puzzle game built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `candy-blast-pro`.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Android APK
This project is a web game, not an APK. To create an APK, package it using an Android WebView or a compatible wrapper tool. APK generation and signing are separate steps.
